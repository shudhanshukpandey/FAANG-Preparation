# Forward Proxy vs Reverse Proxy

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **Forward Proxy**: Protects client identity; handles egress filtering and corporate caching.
- **Reverse Proxy**: Protects origin servers; handles ingress routing, TLS termination, and load balancing.
