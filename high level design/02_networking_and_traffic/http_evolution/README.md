# HTTP Evolution: 1.1 -> 2 -> 3

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **HTTP/1.1**: Persistent connections with head-of-line blocking.
- **HTTP/2**: Binary multiplexing over single TCP socket.
- **HTTP/3**: Independent UDP streams via QUIC protocol eliminating TCP HOL blocking.
