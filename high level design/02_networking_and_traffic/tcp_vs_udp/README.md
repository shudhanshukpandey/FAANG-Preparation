# TCP vs UDP Protocols

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

## Overview
- **TCP**: Connection-oriented, ordered byte-stream with congestion control and automatic retransmission.
- **UDP**: Connectionless, low-overhead datagram protocol used for real-time streaming, voice, and DNS.
