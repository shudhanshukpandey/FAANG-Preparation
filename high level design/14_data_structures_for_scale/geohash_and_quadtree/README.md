# Geohashing & Quadtrees

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **Geohash**: Hierarchical base32 spatial string encoding; prefix matching queries adjacent geographical bounding boxes.
- **Quadtree**: 2D spatial tree dividing space recursively into 4 quadrants (NW, NE, SW, SE) for Uber driver lookup.
