# RBAC & Attribute-Based Access Control (ABAC)

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **RBAC (Role-Based)**: Static permissions mapped to roles (Admin, Editor, Viewer).
- **ABAC (Attribute-Based)**: Evaluates dynamic context: subject, resource, action, environment (e.g. time, IP subnet, document owner).
