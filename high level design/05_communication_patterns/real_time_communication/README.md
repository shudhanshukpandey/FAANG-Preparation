# Real-Time Protocols: WebSockets, SSE & Long Polling

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **WebSockets**: Full-duplex persistent bidirectional TCP channel.
- **Server-Sent Events (SSE)**: Unidirectional server-to-client streaming over HTTP.
- **Long Polling**: Request holds open until server has data; high reconnect overhead.
