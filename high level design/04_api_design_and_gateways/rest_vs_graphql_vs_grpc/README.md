# REST vs GraphQL vs gRPC

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **REST**: Standard HTTP/JSON resource verbs (GET/POST/PUT/DELETE).
- **GraphQL**: Single endpoint with client-specified schema queries; prevents over/under-fetching.
- **gRPC**: High-throughput inter-service RPC over HTTP/2 using Protocol Buffers binary serialization.
