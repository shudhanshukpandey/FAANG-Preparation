# SQL vs NoSQL Databases

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **SQL**: Rigid tabular schemas, ACID transactions, relational foreign keys, normalized tables.
- **NoSQL**: Dynamic schema (Document, Key-Value, Column, Graph), horizontal scale, denormalized nested data.
