# Specialized Databases: Time-Series, Graph & Vector

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **Time-Series (TSDB)**: Optimized for append-only timestamped metrics (Prometheus, InfluxDB).
- **Graph Databases**: Optimized for index-free adjacency traversal (Neo4j, AWS Neptune).
- **Vector Databases**: Optimized for high-dimensional nearest neighbor embeddings search (Milvus, Pinecone, Qdrant).
