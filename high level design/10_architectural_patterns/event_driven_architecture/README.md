# Event-Driven Architecture (EDA)

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **Choreography**: Services react to events published on a message broker without a central orchestrator.
- **Benefits**: Extreme loose coupling; asynchronous processing; easy addition of new downstream consumers.
