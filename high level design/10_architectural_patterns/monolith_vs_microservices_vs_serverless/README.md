# Monolith vs Microservices vs Serverless

> [!TIP]
> **Interactive Diagram**: Open [diagram.html](diagram.html) in your browser to explore the interactive animated data flow with theme toggles and SVG/image export.

- **Monolith**: Single codebase and binary deployment; zero network overhead between modules; hard to scale independently.
- **Microservices**: Independent deployment, technology polyglot; network latency and distributed coordination complexity.
- **Serverless**: Event-driven stateless compute (AWS Lambda); auto-scales to zero; cold starts and timeout limits.
